# V2.0 AI Lab: Boundary Note

Status: **boundary note only.** V2.0 is not designed here, and no V2 branch exists. Recorded 2026-09-25 during V1.5 Slice 0.

## What V2.0 is

A separate, experimental track after the stable V1.x line (V1.5 = Ads + Android shipping). It holds only the ideas already
agreed:
- **AI-assisted photo colour estimation:** a possible improvement on the deterministic V1.x Photo Color Checker, whose
  colour differences are accepted as a V1.x limitation.
- **Possibly, generative outfit visualization.**

## What is already understood

- V2 may need a backend, an API or model inference, which can carry a **running cost**.
- V2 may start as **private or personal use** only.

## What V2.0 is not

- **Not part of V1.5.** V1.5 contains no generative AI, no AI colour estimation or photo correction, no vision garment
  understanding, no AI outfits or stylist chat, no paid inference API, no AI backend, and no AI credits or subscriptions.
- **Not a reason to reshape V1.x.** V1.5 does not add structure for speculative V2 needs. The deterministic engines
  (classifier, palettes, Photo sampling and matching, Daily) stay as released.

## Boundary rules until V2 is planned

- V1.x stays local-first: no app data leaves the device through the app's own code (V1.5 plan §17–18).
- Any future V2 work starts from its own plan and branch, and its own privacy review.
